01 PROFILE

소개

자연어 요청을 실제로 작동하는 에이전트 워크플로우로 설계하는 AI 엔지니어입니다.

현장의 문제를 스스로 정의하고, 해법을 구조화해 업무에 정착시킵니다. 도메인 규칙, 데이터, 도구, 알고리즘을 하나의 실행 흐름으로 연결합니다.

의류 영업과 소싱 데이터 실무, 추천시스템 개발 경험을 토대로 LLM Agent를 만들고 있습니다. 제가 만든 도구로 막힌 지점을 풀고, 사용자가 스스로 해내는 순간을 가장 중요하게 생각합니다.

  • OWNERSHIP도입까지 책임진다. 문제를 스스로 정의하고, 도구와 구조를 만들어, 현장에 자리 잡을 때까지 끌고 간다.
  • AGENT WORKFLOW실행형 파이프라인 설계. 의도분석, 실행계획, 툴호출, 검증, 응답을 하나의 흐름으로 구성한다.
  • RAG RELIABILITY신뢰할 수 있는 응답. 실데이터 grounding으로 환각을 억제하고 근거를 남기는 구조를 만든다.
  • RECSYS → AGENT추천에서 에이전트로. MF, FM, NeuMF, SASRec 기반을 LLM 멀티에이전트로 확장한다.

      앞으로 5년

      Agent로 서비스와 서비스를 잇고, 한 기업을 넘어 분야 전체가 돌아가는 생태계를 만든다.

      지금까지 만든 실행형 에이전트와 제약 최적화, 추천 경험을 이어, 사람이 막혀 있던 지점을 자동으로 푸는 도구를 여러 도메인에서 재사용 가능한 형태로 표준화하는 것이 목표입니다.

      ~1-2년
      실행형 아키텍처 정착. 제약 최적화와 LLM Agent를 한 제품 안에서 결합해 현장에서 운영되는 구조로 완성.
      2-3년
      도메인 확장. 인력 운영을 넘어 제조, 교육 등에서 재사용 가능한 Agent 워크플로우로 표준화. 로컬 LLM 도메인 특화 단일 에이전트 최적화 병행.
      4-5년
      서비스 연결과 생태계. 흩어진 서비스를 Agent로 연결해, 한 기업을 넘어 분야 단위로 굴러가는 의사결정 생태계 구축.

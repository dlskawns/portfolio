01

소개

나를 움직이는 건 특정 기술이 아니라, 내가 만든 도구로 사람이 막혀 있던 지점을 풀어 스스로 할 수 있게 되는 순간입니다.

의류 영업과 소싱 데이터 실무에서 출발해 Data Scientist를 거쳐 지금은 LLM Agent 기반 업무 자동화와 AI 서비스를 만듭니다. 도메인은 계속 바뀌었지만, 문제를 스스로 정의하고 도구와 구조로 풀어 현장에 정착시키는 일은 한 번도 바뀌지 않았습니다.

추천시스템은 그 방향의 이전 형태였고, 지금은 에이전트가 같은 목적의 현재 형태입니다. 만들었다에서 끝내지 않고 실제로 채택되어 가치를 냈다까지 책임지는 것을 제 일의 기준으로 삼습니다.

  • 01 오너십도입까지 책임진다. 멀티에이전트 콘텐츠 생성 누락률 40%에서 3%, 온보딩 설정 문의 10~15건에서 5~6건으로.
  • 02 실행형 Agent 설계의도분석, 실행계획, 툴호출, 검증, 응답 파이프라인을 하나의 실행 흐름으로 구성.
  • 03 RAG 신뢰성 제어실데이터 grounding으로 환각률 65%에서 17%까지 축소.
  • 04 추천에서 에이전트로MF, FM, NeuMF, SASRec 기반을 LLM 멀티에이전트로 확장.

사내 데이터 셀프서비스 (Text2SQL)

역할 AI Engineer 담당 레거시 정제, 데이터 마트 설계, 자연어 질의 연결 기간 2025.03 ~ 재직중
Text2SQLMSSQL메타데이터 매핑권한 제어FastAPI시각화

문제

비개발 부서의 수치 확인이 데이터팀 요청과 대기에 의존했습니다. 레거시 시스템은 서비스별로 같은 의미를 다른 컬럼명으로 써서, 자연어 질의를 데이터에 연결할 수 없는 상태였습니다.

안내 문서를 늘리는 문제가 아니라, 부서가 직접 조회하도록 자연어와 데이터 사이를 잇는 문제로 다시 정의했습니다. 다만 운영 데이터를 다루므로, 권한을 통과한 읽기 전용 조회만 허용하는 것이 전제였습니다.

접근

  • 레거시 정제와 데이터 마트. 흩어진 운영 데이터를 단일 기준으로 표준화하고 조회 전용 마트로 재구성. 업무 용어와 실제 컬럼을 잇는 메타데이터 매핑으로 자연어 질의를 데이터에 정합.
  • 권한 우선 설계. 사용자별 접근 권한을 먼저 세우고, 권한을 통과한 읽기 전용 질의만 조회하도록 제한.
  • 시연 기반 확산. 각 팀의 반복 수작업을 현장에서 자동화해 보이는 시연으로 도입 저항을 해소.

결과

약 70%↓
데이터팀 경유 조회 요청
셀프서비스
비개발 직원의 자연어 직접 조회와 시각화

데이터팀을 경유하던 조회 요청을 약 70% 줄였고, 비개발 직원이 자연어로 직접 조회하고 시각화하는 셀프서비스로 전환했습니다.

배운 점

자연어 조회의 병목은 모델이 아니라 레거시 데이터의 의미 불일치였습니다. 업무 용어와 실제 컬럼을 잇는 메타데이터 매핑을 먼저 세우고, 권한을 통과한 읽기 전용 질의만 허용하도록 접근 통제를 조회 앞 단계에 두었습니다.

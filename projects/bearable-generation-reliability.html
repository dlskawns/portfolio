Bearable / 창업경진대회 1위 최우수상 / 2024

멀티에이전트와 RAG 기반 생성 신뢰성 개선

역할 Data / AI Engineer 담당 품질 축 정의, 파이프라인 설계, 평가 체계 기간 2023.09 ~ 2025.02
LangChainLangGraphChromaDBHyDEPyTorchQLoRA (인접 실험)

문제

학생의 진로 활동 추천에서 전공 연계 콘텐츠를 생성할 때 할루시네이션이 늘었습니다. 근거 없이 생성된 사례와 유형별 필수 정보 누락이 동시에, 서로 다른 원인으로 발생해 단일 지표로는 판별할 수 없었습니다.

그래서 품질을 근거성과 완결성 두 지표로 분리하고, 각각에 다른 구조를 적용하는 과제로 재정의했습니다.

접근

  • 완결성. 활동유형과 전공별 포함 요소를 체크리스트로 지표화. 주제 선정부터 최종 검토까지 6개 역할 에이전트로 분기(LangGraph)하고, 최종 검토에서 누락을 발견하면 해당 단계로 되돌려 재생성.
  • 근거성. 참조 근거가 없으면 사례가 지어내지는 문제를 막기 위해 정적 사례 DB(ChromaDB)를 구축하고, 목적별 정적과 동적 검색기를 분리 적용. 표현 격차는 HyDE 임베딩으로 보정하고 검색 근거를 생성 단계에 고정.
  • 인접 실험. 로컬 오픈모델 파인튜닝 타당성을 검증. 후보 3종을 QLoRA 동일 조건으로 파인튜닝해 한국어 품질과 구조적 출력 안정성을 평가.

결과

65 → 17%
사례 생성 할루시네이션율 (100건 기준)
40 → 3%
구성요소 누락률 (100건 기준)
1위
생성형 AI 창업경진대회 최우수상 (경기도지사상, 2024)

근거성과 완결성 축별 평가 데이터셋으로 오류 유형을 개별 추적해, 할루시네이션율을 65%에서 17%로, 구성요소 누락률을 40%에서 3%로 낮췄습니다. 이 서비스로 생성형 AI 창업경진대회 1위 최우수상을 받았습니다.

배운 점

원인이 다른 오류에는 다른 구조를 적용해야 한다는 것을 배웠습니다. 근거성은 검색 근거 고정으로, 완결성은 체크리스트 기반 되돌림 재생성으로 나눠 풀었습니다. 파인튜닝 실험은 성능 향상 자체가 아니라, 형식 안정성이 부족해 로컬로 전환하지 않는다는 의사결정을 데이터로 뒷받침한 사례였습니다.

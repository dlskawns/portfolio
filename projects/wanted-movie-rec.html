설명 가능한 개인화 영화 추천 파이프라인

역할 프롬프트 엔지니어링, 구조화 팀 가짜연구소 3인 기간 2024.07
HyperCLOVA HCX-003LangGraphChromaDBElastic SearchTMDB APIDjangoOpenshift

문제

영화 추천 결과의 설명 가능성 부족이 사용자 경험을 저해합니다. 대규모 플랫폼도 왜 이 콘텐츠가 추천됐는지 명확한 설명을 주지 못합니다. 설명 가능하고 개인화된 추천을 목표로 기획했습니다.

접근

PALR(Personalization Aware LLMs for Recommendation) 아이디어를 차용해, HyperCLOVA 구조적 프롬프트와 LangGraph 멀티에이전트 3-flow로 설계했습니다.

  • FLOW 1 유저 특징. is_recommend 에이전트가 라우팅 분기, user_profile 에이전트가 시청 히스토리에서 선호 feature 생성.
  • FLOW 2 메타 추출과 후보 검색. self-query로 메타 검출(예: 봉준호 감독), TMDB API와 Elastic, ChromaDB로 후보 추출.
  • FLOW 3 추천 실행. recommend_movie 에이전트가 CoT로 추천과 설명 작성, relevance_check 에이전트가 적합성 검토, 부적합하면 재추천 루프.
  • 프롬프트 구조화. GOAL, PROCEDURE, FORMAT(JSON), FewShot 구조로 영어 작성해 순차 처리를 안정화.

총 183팀 중 상위 15팀 결선에 진출했습니다. 프롬프트 구조화로 오류 발생률을 최소화하는 과정에서 생성 AI 역량을 크게 넓혔습니다.

회고

영화 추천이라는 비교적 단순한 주제 선정에는 아쉬움이 남았습니다. 다만 멀티에이전트의 발전 가능성을 확인했고, 생성 기반이라도 메타정보 데이터 전처리가 중요하다는 점을 배웠습니다.

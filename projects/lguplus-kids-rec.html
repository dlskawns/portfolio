아이들나라 키즈 OTT 콘텐츠 개인화 추천

역할 데이터 분석, 전처리, 모델 실험 팀 2인 기간 2022.09 ~ 2022.10
PythonPyTorchNeuMFFM LayerPandasNumPySciPy

문제

키즈 콘텐츠는 연령대, 보호자 선택, 장르, 길이가 추천 품질에 크게 영향을 줍니다. EDA로 feature 가설을 세운 뒤 모델 실험으로 검증했습니다.

접근

  • EDA로 가설 수립. 연령대별 장르 선호 차이를 카이제곱 검정(p=0.0)으로 확인하고, 런타임과 소비 횟수 상관을 분석.
  • NeuMF에 메타 결합. baseline에 runtime, sex, view, search, payment feature를 추가.
  • FM Layer 비교. DeepFM을 차용한 2차 상호작용 가설을 실험2로 비교.

결과

상위 5.3%
최종 35위 / 658팀
0.2251
Recall@25 (NDCG@25 0.2065)
0.2204
baseline 0.2136 → Opt2 0.2204

메타 feature 결합으로 baseline(NeuMF) 0.2136을 0.2204로 올렸습니다. FM Layer 추가는 오히려 불안정했고, layer를 더하는 것보다 feature 품질과 score 결합 방식이 중요하다는 결론을 얻었습니다.
